📌 ApexPlanet Internship – Task 2
🎯 Objective

The goal of Task 2 was to build a responsive Contact Page containing:

A Contact Form with input validation (Name, Email, Message).

A To-Do List Application to manage tasks dynamically.

This task enhanced my skills in HTML, CSS, and JavaScript DOM manipulation while practicing form validation and interactive UI design.

🛠️ Tech Stack

HTML5 – Structure of the webpage

CSS3 – Styling and responsive layout

JavaScript (Vanilla JS) – Form validation and task list functionality

📂 Features
1. Contact Form

Fields: Name, Email, Message

Validation rules:

Name cannot be empty

Email must follow standard email format

Message cannot be empty

Displays error messages dynamically.

Shows success alert when submitted correctly.

2. To-Do List

Add new tasks via input field.

Tasks displayed in a styled list.

Each task has a delete button (❌) to remove it.

Real-time updates without reloading.
