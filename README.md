# ApexPlanet Internship Tasks

This repository contains the completed ApexPlanet data analytics and web development tasks.

## Task 1: Telco Customer Churn

The `data/`, `notebooks/`, `scripts/`, `reports/`, and `models/` directories contain the IBM Telco customer churn cleaning, exploratory analysis, visualizations, report, and baseline model.

Run the main analysis from the repository root:

```powershell
py scripts/eda_telco.py
py scripts/analysis_telco.py
py scripts/convert_to_parquet.py
```

## Task 2: SQL Integration and Web Page

The `Task-2/` directory contains the SQL integration project, notebook, ingestion pipeline, processed datasets, and SQL analysis scripts. The root `index.html`, `contact.html`, and `style.css` files contain the responsive contact and to-do page.

The large raw Task 2 CSV is intentionally excluded from Git tracking because GitHub limits individual files to 100 MB.
