# apexplanet-data-analytics

Project: Foundational setup and EDA for Apexplanet data analytics (Task 1).

Structure:

apexplanet-data-analytics/
- data/ (raw, processed)
- notebooks/ (Jupyter notebooks)
- scripts/ (Python scripts)
- reports/ (PDF/PPT)
- dashboards/ (PBIX/TWX files)
- README.md

Quick start

1. Install Anaconda (https://www.anaconda.com).
2. Create conda env: `conda env create -f environment.yml` or `conda create -n analytics python=3.10`
3. Activate: `conda activate analytics`
4. Launch Jupyter: `jupyter notebook` or open a notebook in `notebooks/` in VS Code.
5. To run Telco script: `python scripts/eda_telco.py`

Notes
- The repository contains notebooks and scripts for EDA. Use the Telco notebook (`notebooks/02_EDA_Telco.ipynb`) or the Telco EDA script (`scripts/eda_telco.py`) for the IBM Telco dataset.
 - If you have the IBM Telco customer churn file, place it at the repository root as `Telco_customer_churn.xlsx` (already present in this workspace). Run the Telco EDA script:
	 `python scripts/eda_telco.py`
 - The Telco script will copy the Excel file into `data/raw/`, perform cleaning (convert `TotalCharges` to numeric, drop duplicates, fix dtypes), produce basic EDA, and save cleaned CSV to `data/processed/telco_cleaned.csv`.
 - Analysis artifacts (visuals, model, report) are generated by `scripts/analysis_telco.py` and saved to `reports/` and `models/`.

Reproduce full analysis (recommended):

```powershell
conda env create -f environment.yml
conda activate analytics
python scripts/eda_telco.py
python scripts/analysis_telco.py
```

Key outputs:
- `data/processed/telco_cleaned.csv` — cleaned dataset
- `reports/telco_report.pdf` — EDA and model report
- `models/logistic_telco.pkl` — trained baseline model
- `CLEANING_LOG.md` — documented cleaning steps
- `RESULTS_SUMMARY.md` — concise findings and next steps
